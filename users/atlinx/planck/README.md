# Planck

This keymap folder is for 40% Planck keyboards.

## `rules.mk`
- `PLANCK_TYPE` - Specifies Planck keyboard type
    - Options: `grid`, `mit`
- `RGB_MATRIX_ENABLE` - Enables per-key RGB support, and will use the `glow` keymap
    - Options: `yes`, `no` 
- `AUDIO_ENABLE` - Enables the audio
    - Options: `yes`, `no`
